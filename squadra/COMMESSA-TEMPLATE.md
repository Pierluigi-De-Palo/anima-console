# LA COMMESSA — il modulo del Direttore

Compilalo in 2 minuti e incollalo nella chat di D.R.A.G.O. (o del caposquadra, se vuoi
saltare il dispatch). Ogni campo vuoto è una domanda che ti verrà rifatta: meglio
riempirlo subito. La versione da compilare col mouse è `docs/schede/commessa.html`.

```
COMMESSA · <data>

CLIENTE — chi è e cosa sa di AI (anche "interno" se è per la casa):
NECESSITÀ — cosa serve, con le parole del cliente, in una frase:
OUTPUT ATTESO — cosa deve avere in mano alla fine (pagina, verdetto, testo, script…):
VINCOLI — scadenza, budget-token (es. "spesa minima"/"ultracode"), brand, cosa NON fare:
MATERIALI — link, file, testi che servono (o "nessuno"):
CONSEGNA — dove la vuoi: chat / patch per il repo / docs (HTML):
```

## Esempio compilato

```
COMMESSA · 2026-08-17

CLIENTE — negozio di strumenti musicali, usa l'AI "come Google".
NECESSITÀ — "voglio sapere se il fornitore Pig Hog è roba seria prima di ordinare".
OUTPUT ATTESO — verdetto KIROSHI pubblicabile + una riga da girare al cliente.
VINCOLI — entro domani; spesa minima; niente consigli d'acquisto (canone).
MATERIALI — pighog.com, il preventivo ricevuto (lo incollo sotto).
CONSEGNA — chat + patch per docs/data/.
```

Regole del modulo:
- **Una necessità per commessa.** Due lavori = due commesse (o lo dico io al triage).
- **Le intenzioni riservate restano fuori dai campi** che finiranno su superfici
  pubbliche: se il contesto è sensibile, scrivilo e lo tratto da guardia privacy.
- Le decisioni in corsa te le porto **in un blocco solo, all'inizio**: dopo il via,
  la squadra lavora senza interromperti.
